# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0-pre.1 | :white_check_mark: |
| < 1.0.0   | :x:                |

## Reporting a Vulnerability

We take the security of the We Do Care Global OmniGuard platform seriously. If you believe you have found a security vulnerability, please report it to us as described below.

### Reporting Process

1. **Email**: security@wedocare-global.com
2. **PGP Key**: https://wedocare-global.com/security.txt
3. **Do not** create a public GitHub issue for security vulnerabilities
4. Include the following in your report:
   - Description of the vulnerability
   - Steps to reproduce
   - Affected components and versions
   - Potential impact
   - Suggested fix (if any)

### What to Expect

- We will acknowledge receipt within 48 hours
- We will provide an initial assessment within 5 business days
- We will keep you informed of progress throughout the remediation process
- Public disclosure will be coordinated with you

## Scope

- AgentGuard control plane (`WeDoCareGlobal/agentguard-next`)

- Agent Eval (`WeDoCareGlobal/agent-eval-next`)
- Enterprise Hybrid-RAG (`WeDoCareGlobal/enterprise-hybrid-rag-next`)
- FoundationCentar (`WeDoCareGlobal/FoundationCentar-Next`)
- OmniGuard (`WeDoCareGlobal/OmniGuard-Next`)
- Pharma Intelligence OS (`WeDoCareGlobal/Pharma-Intelligence-Os-Next`)

## Policy

- We do not consider social engineering out of scope
- We do not consider issues requiring physical access out of scope
- We do not consider issues in third-party dependencies out of scope (report to the maintainer instead)
- We do not offer monetary bounties at this time, but will provide public credit

## Acknowledgments

We thank security researchers for their contributions to making the OmniGuard platform safer.
